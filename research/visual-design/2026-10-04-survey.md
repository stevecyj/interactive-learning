# 視覺方向、配色與受眾感受調查

日期：2026-10-04（Asia/Taipei）。範圍是互動教材的視覺身份、分類配色、參考分析與受眾感受；不是前一輪教學互動方法的重做。

## 結論

**有相近且值得深入的 Skill／做法，但沒有一個候選能替這個專案證明「某色系會讓讀者方便、好玩、好奇」。** 最有價值的路線是：先記錄受眾與任務，分析參考作品的視覺機制，形成自己的設計方向，將共同規則與分類 accent 分開，最後分別驗證感受、操作與理解。

Skill 方面優先研究 [Impeccable](https://github.com/pbakaus/impeccable)；持續記錄方面補看 [Google Labs 的 DESIGN.md 格式](https://github.com/google-labs-code/design.md)。前者把既有設計、產品情境與後續設計工作連起來，後者把具體 token 與使用理由保存在可攜的文件中。它們比只給一組 palette 更接近「以後同網站、不同主題、多個 AI Agent 都能接續製作」的需求。**本輪未安裝、未執行，這是依文件能力的評估。**

目前 IPv4 的綠色不需要因為常見就換掉。CSS 中已經有中性閱讀底、深色正文與綠／橘教學角色；六組純色色值配對的文字對比計算也都達 4.5:1。真正要注意的是，一個 `--green` 同時服務章節、按鈕、選中狀態和固定前綴。未來要換身份時應先分清角色，不能把所有綠色一次替換就當作完成 theme。[本輪基線與計算限制](audience-and-reference-analysis.md#現有-html-的樣式基線)

## 「同網站、分類不同色」怎麼理解

這是本次依官方 token 方法整理的**未實作構想**，不是已選定的設計系統。

```text
共同網站身份
  字體階層／閱讀寬度／留白／導覽與控制／形狀／動態原則
       │
       ├─ network 分類：AWS、IP/CIDR → 一組 accent 家族
       └─ java 分類：Java 教材      → 另一組 accent 家族

跨分類的功能與教學契約
  focus／選中／錯誤／成功；固定輸入／變動輸入／推導結果
  保持意義與標記一致，不能被分類 accent 任意改寫
```

共同身份可以保留相近的背景與正文。分類差異可表現在章節識別、少量操作重點、封面或內容圖解的特定 accent，不需要整頁全部換色。功能色的**意義與可辨識性**穩定，但明暗模式下的實際數值仍可調整；不把「同一語意」誤解成任何背景都硬用同一 hex。

教學圖解依內容決定需要哪些角色，並搭配標籤、線型、形狀或位置。若 Java 在說執行堆疊，不必硬套 CIDR 的網路／主機名稱；應沿用網站的閱讀與互動語法，再正確表達該課模型。[W3C Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)

### 如何相近但不平均

分析參考的「關係」，再做自己的表達：例如留白如何讓操作突出、色彩在哪一個狀態出現、標題與數值如何分工、動態何時指出改變。保留這些關係，可以重新安排 hue／chroma、形狀或一個與內容有關的視覺特徵；不必照搬品牌色，也不必用罕見色碼追求罕見。

需要兩種比較：初期比較整體視覺方向，可以改多個元素；之後想知道**配色本身**的差異，才固定同一教材、字體、layout 和互動只換 palette。兩種結果分開解讀。配色比例、單 accent、60/30/10、8px spacing 等是具體系統或作者的選擇，不能全變成本專案的必選規則。[完整參考拆解方法](audience-and-reference-analysis.md#將參考作品拆開再重新組合)

「方便」優先看能否找到操作和讀懂結果；「好玩」優先看試錯與因果回饋；「好奇」優先看預測、探索與揭示是否有解釋。**沒有唯一對應的色相。** 色彩情緒研究不是「綠＝護眼、橘＝好玩」字典，而且研究刺激、文化與任務有適用限制。[原始研究與閱讀深度](design-methods-and-evidence.md#色彩感受的實證邊界)

## 哪些案例適合這次需求

- **Khan Academy／Duolingo**：優先看共同 token、字體／形狀身份、多方向原型與跨區域的一致性。
- **The Pudding／Our World in Data**：看共同閱讀介面如何容納每個故事或圖表的色彩差異。
- **Red Blob／Ciechanowski／PhET**：看局部 accent、線條與狀態如何服務正在解釋的變數。
- **Awwwards／CSS Design Awards**：看構圖和視覺個性；獎項是策展與評分訊號，沒有證明教材更好懂。

這些是本專案的參考選擇，不是宣稱它們在同一全球榜單排名前幾。官方／原作者連結、視覺特徵、年份／獎項和影片狀態都放在 [案例文件](reference-sites-and-videos.md)。影片未觀看的項目只記 metadata；有逐字稿的另標閱讀狀態。

**已做**：三輪查找與來源補查、原始 Skill／官方方法閱讀、GitHub metadata 快照、六個網站頁面的實際視覺拆解、既有 CSS 基線、六組純色對比計算；另用瀏覽器操作 Realtime Colors 的 Primary hue，以及 Huemint 的 Generate，確認色彩與同版面預覽連動。[操作細節](audience-and-reference-analysis.md#實際瀏覽器操作紀錄)
